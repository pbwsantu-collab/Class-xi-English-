📚 Class XI English Master Hub 🚀

🌈 An Interactive English Learning Platform for Class XI Students

Welcome to Class XI English Master Hub — a colourful, mobile-friendly and interactive study platform designed to bring Class XI English lessons, poems, dramas, vocabulary, MCQs, revision resources and video lessons together in one place.

«🎓 Learn • Practise • Revise • Master English»

---

✨ What Makes It Special?

Feature| Description
📖 Digital Literature Library| Access all major Class XI lessons from one dashboard
🧠 Interactive Learning| Lesson-wise study resources and practice
🔤 Vocabulary Support| Build vocabulary while studying literature
🇮🇳 Bengali Meaning Support| Helpful English → Bengali learning assistance
📝 MCQ Practice| Test your understanding after studying
🎥 Video Learning| Direct access to curated YouTube playlists
🔎 Smart Search| Quickly find a lesson or topic
⭐ Favourite Lessons| Mark important lessons for quick access
📊 Progress Tracking| Track lessons you have already visited
🌙 Dark Mode| Comfortable reading in low-light conditions
📝 My Notes| Save personal revision notes in your browser
📱 Mobile Friendly| Designed especially for smartphone learning
⚡ Fast & Lightweight| No heavy frameworks or external libraries
